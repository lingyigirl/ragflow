高中数学核心知识整理（含典型习题示例）

高中数学知识体系分为代数、几何、概率统计三大板块，涵盖12个核心模块，以下是各模块的知识点梳理与配套习题示例，兼顾基础与高频考点。

# 一、集合与常用逻辑用语

核心知识点

1. 集合的表示方法：列举法、描述法、韦恩图法；元素与集合的关系  $(\in, \in /)$ ，集合与集合的关系  $(\subseteq, \nsubseteq, =, \nsubseteq)$ 。

# 2. 集合的运算：

交集：且  
。并集：或  
。补集：且（U为全集）

# 3. 常用逻辑用语

四种命题：原命题  $\rightarrow$  逆命题  $\rightarrow$  否命题  $\rightarrow$  逆否命题（互为逆否命题的真假性相同）。  
。充分条件与必要条件：  $\mathrm{p}\Rightarrow \mathrm{q}$  ，则  $\mathfrak{p}$  是  $\mathbf{q}$  的充分条件，  $\mathrm{q}$  是  $\mathfrak{p}$  的必要条件；  $\mathrm{p}\Leftrightarrow \mathrm{q}$  ，则  $\mathrm{p}$  是  $\mathbf{q}$  的充要条件。

典型习题示例

例1已知集合  $A = \{x\mid x2 - 3x + 2 = 0\}$  ，  $B = \{x\mid 0 <   x <   5,x\in N\}$  ，求  $A\cap B$  ，  $A\cup B$

# 解答：

1. 解方程  $x2 - 3x + 2 = 0$ ，得  $(x - 1)(x - 2) = 0$ ，∴  $A = \{1, 2\}$ 。  
2. 由  $0 < x < 5$  且  $x \in \mathbb{N}$ ，得  $B = \{1, 2, 3, 4\}$ 。  
3.  $\mathrm{A} \cap \mathrm{B} = \{1,2\}$ ,  $\mathrm{A} \cup \mathrm{B} = \{1,2,3,4\}$ 。

例2“  $\mathrm{x} > 2$  ”是“  $\mathrm{x}2 - 3\mathrm{x} + 2 > 0$  ”的（）

A. 充分不必要条件 B. 必要不充分条件 C. 充要条件 D. 既不充分也不必要条件

# 解答：

解不等式  $x2 - 3x + 2 > 0$  ，得  $x < 1$  或  $x > 2$

或，：选A。

# 二、函数与导数

核心知识点

# 1. 基本初等函数

指数函数: 且, 定义域  $\mathrm{R}$ , 值域  $(0, +\infty)$ ;  $a > 1$  时单调递增,  $0 < a < 1$  时单调递减。  
对数函数: 且, 定义域  $(0, +\infty)$ , 值域 R;  $a > 1$  时单调递增,  $0 < a < 1$  时单调递减。  
$\circ$  幂函数：  $y = x a$  （a为常数)，常见形式：  $y = x, y = x2, y = x3, y = x21$ $y = x - 1$  。

2. 函数的性质：单调性（定义法、导数法判断）、奇偶性  $(\mathrm{f}(-\mathrm{x}) = \mathrm{f}(\mathrm{x})$  为偶函数，  $\mathrm{f}(-\mathrm{x}) = -\mathrm{f}(\mathrm{x})$  为奇函数）、周期性  $(\mathrm{f}(\mathrm{x} + \mathrm{T}) = \mathrm{f}(\mathrm{x}), \mathrm{T} \cdot = 0)$  。

# 3. 导数的应用

导数的几何意义:  $f^{\prime}(x_0)$  是曲线  $y = f(x)$  在点  $(x_0, f(x_0))$  处的切线斜率。  
单调性：  $\mathrm{f}^{\prime}$  (x)>0⇒f(x)单调递增；  $\mathrm{f}^{\prime}$  (x)<0⇒f(x)单调递减。  
。极值： $\mathrm{f}'$ $(\mathrm{x0}) = 0$  且  $\mathrm{x0}$  两侧导数符号改变，则  $\mathrm{f}(\mathrm{x0})$  为极值；极大值 / 极小值需判断符号变化方向。  
• 最值: 闭区间  $[a, b]$  上的最值, 需比较端点值  $f(a), f(b)$  和区间内极值。

典型习题示例

例1求函数  $f(x) = x3 - 3x2 + 2$  的单调区间和极值。

# 解答：

1. 定义域为R，求导得  $f'(x) = 3x^2 - 6x = 3x(x - 2)$ 。  
2. 令  $f'(x) = 0$ ，解得  $x = 0$  或  $x = 2$ 。

3. 列表分析：

$$
\begin{array}{l l l l l} \mathrm {x} & (- \infty , 0)   0 & (0, 2)   2 & (2, + \infty) \\ \mathrm {f} ^ {\prime} & (\mathrm {x})   + & 0 & -     0 & + \end{array}
$$

f(x) 递增 极大值2递减 极小值-2递增

4. 单调递增区间：  $(- \infty, 0)$  和  $(2, + \infty)$ ；单调递减区间：  $(0, 2)$ ；极大值  $f(0) = 2$ ，极小值  $f(2) = -2$ 。

例2求曲线  $y = \ln x$  在点(1,0)处的切线方程。

# 解答：

1. 求导得  $y' = x_1$ ，则切线斜率  $k = y'$ $x = 1 = 1$ 。  
2. 由点斜式得切线方程：  $y - 0 = 1 \times (x - 1)$ ，即  $y = x - 1$ 。

# 四、数列

核心知识点

# 1. 等差数列

。通项公式：an=al+(n-1)d（d为公差）。  
。求和公式：  $\mathrm{Sn = 2n(a1 + an) = na1 + 2n(n - 1)d}$  
$\mathrm{O}$  性质：若  $\mathrm{m + n = p + q}$  ，则  $\mathrm{am + an = ap + aq}$

# 2. 等比数列

。通项公式：an=alqn-1（q为公比，  $q\cdot = 0$  ）。  
$\circ$  求和公式：  $\mathrm{Sn =}$  {na11-qa1(1-qn)=1-qa1-anq(q=1)(q·=1)。  
$\mathrm{O}$  性质：若  $\mathrm{m + n = p + q}$  ，则am·an=ap·aq。

3. 数列求和方法: 裂项相消法 (如  $n(n + 1)l = n1 - n + 11$ )、错位相减法 (等差  $\times$  等比型数列)、分组求和法。

典型习题示例

例1已知等差数列  $\{\mathrm{an}\}$  中，  $a3 = 5$  ，  $a5 = 9$  ，求数列  $\{\mathrm{an}\}$  的通项公式和前  $\mathbf{n}$  项和Sn。

# 解答：

1. 设公差为  $\mathrm{d}$ ，则  $\{\mathrm{a1} + 2\mathrm{d} = 5\mathrm{a1} + 4\mathrm{d} = 9$ ，解得  $\{\mathrm{a1} = 1\mathrm{d} = 2$ 。  
2. 通项公式：  $\mathrm{an} = 1 + (\mathrm{n} - 1) \times 2 = 2\mathrm{n} - 1$  
3. 前  $n$  项和：  $\mathrm{Sn} = 2\mathrm{n}(1 + 2\mathrm{n} - 1) = \mathrm{n}2$

# 六、概率与统计

核心知识点

1. 古典概型：事件包含的基本事件数试验的基本事件总数（基本事件等可能）。  
2. 离散型随机变量：分布列（ $\Sigma \mathrm{pi} = 1$ ）、数学期望  $\operatorname{E}(\mathrm{X}) = \sum \mathrm{x}$  ipi、方差  $\mathrm{D}(\mathrm{X}) = \sum (\mathrm{xi} - \mathrm{E}(\mathrm{X}))2\mathrm{pi}$ 。

典型习题示例

例 掷两枚质地均匀的骰子，求点数之和为 7 的概率。

# 解答：

1. 试验的基本事件总数为  $6 \times 6 = 36$  
2. 点数之和为 7 的基本事件有 (1, 6), (2, 5), (3, 4), (4, 3), (5, 2), (6, 1), 共 6 个。  
3. 概率  $\mathrm{P} = 366 = 61$
