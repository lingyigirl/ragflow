# 一、应收款项与坏账准备（备抵法）

核心公式

# 1. 余额百分比法基础公式

。期末应计提坏账准备余额 = 期末应收款项账面余额 × 坏账计提比例  
当期实际应计提坏账准备  $=$  期末应计提坏账准备余额 - 坏账准备账户已有贷方余额（若为借方余额则加绝对值）

# 2. 账龄分析法（拓展公式）

期末应计提坏账准备余额  $= \Sigma$  （某账龄组应收款项余额  $\times$  对应账龄计提比例）

计算例题

例题1：甲公司2024年末应收账款账面余额200万元，其中账龄1年以内150万元（计提比例  $5\%$  ），1-2年50万元（计提比例  $10\%$  )。坏账准备账户期初贷方余额3万元。

- 步骤 1: 计算期末应计提坏账准备余额

$$
= 150 \times 5 \% + 50 \times 10 \% = 7.5 + 5 = 12.5 \text{万元}
$$

- 步骤2：计算当期实际应计提坏账准备

$$
= 1 2. 5 - 3 = 9. 5 \text {万 元}
$$

例题2：若例题1中坏账准备账户期初为借方余额2万元

- 当期实际应计提坏账准备  $= 12.5 + 2 = 14.5$  万元

# 例题3：计划成本法

- 材料成本差异率  $= (-500 - 200) \div (5000 + 10000) \times 100\% = -4.67\%$  
- 发出材料实际成本  $= 8000 \times (1 - 4.67\%) = 7626.4$  元

# 四、无形资产摊销

核心公式

(与固定资产年限平均法逻辑一致，无残值时)

- 年摊销额 = 无形资产入账价值 ÷ 预计使用年限  
- 月摊销额 = 年摊销额 ÷ 12

计算例题

例题：丁公司购入一项专利技术，入账价值36万元，预计使用10年，无残值。

- 年摊销额  $= 36 \div 10 = 3.6$  万元/年

- 月摊销额  $= 3.6 \div 12 = 0.3$  万元/月

# 五、利润与所得税计算

# 核心公式

1. 营业利润 = 营业收入 - 营业成本 - 税金及附加 - 销售费用 - 管理费用 - 财务费用 - 信用减值损失 - 资产减值损失 + 公允价值变动收益 (- 损失) + 投资收益 (- 损失) + 其他收益  
2. 利润总额  $=$  营业利润  $+$  营业外收入  $-$  营业外支出  
3.所得税费用  $=$  应纳税所得额  $\times$  所得税税率（一般  $25\%$  ）

（无纳税调整时，应纳税所得额  $=$  利润总额）

4. 净利润 = 利润总额 - 所得税费用

# 计算例题

例题：戊公司2024年数据（单位：万元）

营业收入1000，营业成本500，税金及附加30，销售费用80，管理费用50，财务费用20，投资收益40，营业外收入10，营业外支出5，所得税税率  $25\%$  （无纳税调整）。

营业利润  $= 1000 - 500 - 30 - 80 - 50 - 20 + 40 = 360$  万元  
- 利润总额  $= 360 + 10 - 5 = 365$  万元  
所得税费用  $= 365 \times 25\% = 91.25$  万元  
净利润  $= 365 - 91.25 = 273.75$  万元

# 六、应交增值税（一般纳税人）

# 核心公式

1. 含税销售额换算：不含税销售额  $=$  含税销售额  $\div$  （1 + 增值税税率）  
2. 销项税额 = 不含税销售额  $\times$  适用税率（货物  $13\%$  、服务  $6\%$  等）  
3. 当期应纳税额 = 当期销项税额 - 当期可抵扣进项税额（进项税额为增值税专票注明税额）  
4. 留抵税额 = 当期进项税额 - 当期销项税额（正数时留抵下期）

# 计算例题

例题：己公司为一般纳税人（货物税率  $13\%$ ），2024年11月销售商品含税收入226

万元，购进原材料取得专票注明进项税额15万元。

- 不含税销售额  $= 226 \div (1 + 13\%) = 200$  万元  
销项税额  $= 200 \times 13\% = 26$  万元  
当期应纳税额  $= 26 - 15 = 11$  万元

# 七、应付债券（平价发行）

核心公式

- 每期应付利息 = 债券面值  $\times$  票面利率  
- 每期利息费用 = 应付利息（平价发行时，利息费用 = 应付利息）

计算例题

例题：庚公司发行5年期平价债券，面值总额500万元，票面年利率  $6\%$  ，每年付息一次。

每年应付利息  $= 500 \times 6\% = 30$  万元  
每年利息费用  $= 30$  万元
