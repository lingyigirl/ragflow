# 9.3 金融宣教与员工培训

持续优化培训体系，将《消费者权益保护法实施条例》纳入必修课程，开展金融营销宣传规范、产品服务信息披露、账户管控等实务操作培训。通过典型案例研讨和现场演练，不断强化员工的消费者权益保护意识，提升服务技能和专业知识水平，为客户提供更优质、专业的金融服务。

# 9.4 投诉渠道与处理

持续优化投诉处理机制，开通  $7 \times 24$  小时人工咨询和投诉服务专线（96839），确保投诉渠道畅通无阻。全年处理外部转办消费投诉26件，涵盖借记卡、账户管控、储蓄存款、个人住房贷款及其他消费贷款等业务类型。投诉分布区域为绵阳地区22件，成都地区2件，广元和南充地区各1件。投诉办结率  $100\%$  ，投诉处理满意度持续提升。

# 第十节 履行社会责任

# 10.1 党建引领，筑牢发展根基

强化党的领导，明确发展方向。以习近平新时代中国特色社会主义思想为指引，坚决拥护“两个确立”，增强“四个意识”、坚定“四个自信”、做到“两个维护”。在经营管理中，将党的领导贯穿始终，把党委会审议作为“三重一大”决策前置程序，保障业务发展与党的要求同步。

推进从严治党，打造清廉生态。深化全面从严治党，签订《党风

廉政建设目标责任书》，完善防控机制，加强党员干部监督。扎实开展党纪学习教育，推动依法合规经营，一体推进“不敢腐、不能腐、不想腐”。强化重点领域监督，规范流程，加强审计检查，严格廉政档案管理。推进风腐同治，精简会议文件，优化营商环境。打造“清廉蜀风”品牌，强化廉政教育，营造廉洁氛围。

严守风险底线，培育合规文化。加强全面风险管理，完善内控制度和风险管控体系，运用技术工具助力评估风险，合理调整业务策略。构建合规文化，将合规操作纳入培训体系，提升员工合规意识。健全考核机制，促使员工严守合规底线。

# 10.2 服务实体，赋能经济发展

贯彻国家政策，担当金融责任。积极响应国家、省、市经济金融政策，制定系列文件，将政策转化为信贷指南，引导资源流向实体经济。主动加强对接沟通，了解客户需求，优化金融服务，聚焦重点领域加大投放。全年累计投放贷款1034.22亿元，同比增长  $26.75\%$  ，大力支持地方经济建设。

服务重大战略，支持重点领域。深度参与成渝双城经济圈建设，发挥自身优势提供金融支持。全力支持“中国科技城”建设，构建科技金融体系，创新产品服务，支持科技型企业167户，贷款余额66.29亿元。围绕“五市战略”加大信贷投放，推出专属服务，助力产业升级和经济协调发展。

促进产业链升级，优化经济循环。支持地方主导产业升级，加大对各产业投入，推动产业集聚。创新供应链金融模式，新增供应链平台用户430户，融资投放新增29.84亿元，增强产业链竞争力。拓展跨境金融业务，为自贸试验区建设、外贸业务和企业“走出去”等方面提供金融服务支持。

稳定房地产市场，落实金融政策。推动房地产融资协调机制落地，加大“白名单”项目贷款投放。落实个人住房贷款调整政策，减轻购房者负担，支持住房需求，促进市场稳定。

# 10.3 改革创新，做好金融“五篇大文章”

发展科技金融，驱动创新发展。创新工作机制，加强部门协同，建立考核激励机制，加大对科技企业支持，全年累计投放科创企业贷款52.91亿元。创新科技专项贷款等产品服务，推动“科技—产业—金融”协同发展。支持制造业“智改数转”，提供“智数E融”、“设备新易融”两个专属金融服务品牌，全年向制造业提供融资58.02亿元，同比增长  $7\%$  。

发展绿色金融，引领低碳转型。完善绿色金融工作体系，明确各层级和部门职责，成立工作小组，健全绿色金融制度，培育绿色金融文化。创新“环保贷”、“海绵贷”等绿色金融产品，开展碳金融业务，支持绿色试点。报告期末，绿色信贷余额25.73亿元，同比增速 $28.20\%$ 。推进绿色银行建设，践行绿色办公，努力打造生态银行、绿色银行。

发展普惠金融，助力小微成长。压实普惠金融责任，完善制度，规范流程。加大普惠信贷投放，优化审批，降低成本。用好政策工具，支持小微企业发展，落实多项试点工作。全年累计发放普惠小微企业贷款147.17亿元。

发展养老金融，守护幸福晚年。支持养老产业发展，创新服务模式。完善养老金融产品，提供专属存款产品和特色服务。加强“适老化”服务，建设的特色网点受到央行肯定并被央视新闻报道。开展“敬老专属”系列活动，提升服务品质。

发展数字金融，加快转型步伐。加强与数字经济产业园区合作，提供知识产权质押贷款等定制化服务，助力数字经济发展。数字赋能

经营管理，有2项研究成果获得国家发明专利。普及数字化服务，增加智能设备，推广线上平台，提高客户认知度和使用率。

# 10.4 服务提升，践行社会责任

优化客户体验，提供暖心服务。推进服务标准化建设，全年新获评4个四星级网点。强化服务质量监督机制，优化业务流程，减少冗余环节，提高效率。开展财富管理论坛、健康讲座等特色客户活动，增强客户粘性和认同感。

关爱员工成长，凝聚发展合力。健全人才选拔机制，搭建人才发展平台，开展多形式业务培训，构建公平考评体系，拓宽员工晋升和职业发展双通道。强化员工福利保障，广泛开展职工文体活动，获评“全国模范职工之家”。

热心公益事业，传递社会正能量。积极投身公益，全年全行对外捐赠款物145万余元。选派4名优秀干部驻村帮扶，投入帮扶资金20万元，助力乡村振兴。关爱户外劳动者，在银行网点设立“户外劳动者服务站点”。开展志愿服务200余次，彰显社会责任担当，促进社会和谐。
