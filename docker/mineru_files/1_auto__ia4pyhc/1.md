初三数学核心知识点总结

初三数学知识以代数、几何、统计与概率三大模块为主，是中考的核心考查内容，同时也是对初中前两年知识的整合与深化。以下是分模块的系统总结：

# 一、代数模块（中考占比约  $40\%$ ）

1. 一元二次方程

• 定义: 只含一个未知数, 且未知数最高次数为 2 的整式方程, 一般形式为  $a x^{2} + b x + c = 0 \quad (a \cdot = 0)$  。

解法

1. 直接开平方法：适用于  $(\mathrm{x} + \mathrm{m})2 = \mathrm{n}$  （  $n\geqslant 0$  ）的形式。  
2. 配方法：通过配方转化为  $(x + m)2 = n$  ，步骤为“移项  $\rightarrow$  二次项系数化为  $1 \rightarrow$  配方  $\rightarrow$  开方”。  
3. 公式法：求根公式  $x = 2a - b \pm b2 - 4ac$ ，前提是判别式  $\Delta = b2 - 4ac \geqslant 0$ 。  
4. 因式分解法：适用于方程能分解为  $(x - x1)(x - x2) = 0$  的形式，根为  $x1$ ， $x2$ 。

- 判别式的作用

。  $\Delta > 0$  ：方程有两个不相等的实数根；  
$\Delta = 0$  ：方程有两个相等的实数根；  
。  $\Delta < 0$  ：方程无实数根（有两个共轭虚数根）。

- 根与系数的关系（韦达定理）

若方程  $\mathrm{ax2 + bx + c = 0}$  （a·=0）的两根为  $x1, x2$ ，则  $x1 + x2 = -ab$ ， $x1x2 = ac$ 。

2. 二次函数

- 定义：形如  $y = ax + bx + c$  （ $a \cdot = 0$ ）的函数，图像是抛物线。  
三种表达式

1. 一般式：  $y = ax + bx + c$  （ $a \cdot = 0$ ）；  
2. 顶点式:  $y = a(x - h) 2 + k$  (a  $\cdot = 0$ ), 顶点坐标为  $(h, k)$ , 对称轴为直线  $x = h$ ;  
3. 交点式:  $y = a(x - x1)(x - x2)$  (a  $\cdot = 0$ ), 其中  $x1, x2$  是抛物线与  $x$  轴交点的横坐标。

# 系数作用

# - 最值

。当  $a < 0$  时，抛物线开口向下，在  $x = -2ab$  处取得最大值  $y = 4a4ac - b2$  。

# 与一元二次方程的关系

抛物线  $y = ax + bx + c$  与  $x$  轴的交点个数对应方程  $ax + bx + c = 0$  的实数根个数：

2 个交点  $\Leftrightarrow \Delta >0$  
。1个交点（顶点在  $\mathbf{X}$  轴上）  $\Leftrightarrow \Delta = 0$  
无交点  $\Leftrightarrow \Delta < 0$

# 3. 反比例函数

- 定义：形如  $y = x k$  （ $k \cdot = 0, x \cdot = 0$ ）的函数， $k$  为比例系数。

# 图像与性质

# $\mathrm{k}$  的符号图像位置 增减性

k>0 第一、三象限在每个象限内，y随x的增大而减小

k<0 第二、四象限在每个象限内，y随x的增大而增大

- 几何意义: 过反比例函数图像上任意一点作  $x$  轴、 $y$  轴的垂线, 所得矩形的面积为  $|k|$  。

# 4. 分式方程与二次根式

# - 分式方程

1. 定义：分母中含未知数的方程。

2. 解法：去分母转化为整式方程  $\rightarrow$  解整式方程  $\rightarrow$  验根（检验分母是否为0，增根需舍去）。

# 二次根式

1. 有意义的条件：被开方数为非负数，即 a 中  $a \geqslant 0$ 。  
2. 性质：(a)  $2 = a$  (a≥0)；a2=|a|。  
3. 运算: 加减时先化为最简二次根式, 再合并同类二次根式; 乘除时  $a \cdot b = ab (a \geqslant 0, b \geqslant 0)$ ,  $ba = ba (a \geqslant 0, b > 0)$  。

# 二、几何模块（中考占比约  $45\%$ ）

1. 圆的相关知识

# 圆的基本概念

。圆心：确定圆的位置；半径：确定圆的大小。  
。弦：连接圆上两点的线段；直径是圆中最长的弦。  
。 弧：圆上两点间的部分，分为优弧、劣弧和半圆。

# 圆的基本性质

1. 对称性：圆是轴对称、中心对称图形，对称轴是任意一条过圆心的直线。  
2. 垂径定理：垂直于弦的直径平分弦，且平分弦所对的两条弧。  
3. 圆心角、弧、弦的关系：在同圆或等圆中，相等的圆心角所对的弧相等，所对的弦相等（知一推二）。  
4. 圆周角定理: 同弧或等弧所对的圆周角相等, 都等于该弧所对的圆心角的一半;直径所对的圆周角是直角 (90°); 90° 的圆周角所对的弦是直径。

# - 点、直线与圆的位置关系

1. 点与圆：设圆半径为  $r$ ，点到圆心距离为  $d$

-  $\mathrm{d} < \mathrm{r} \rightarrow$  点在圆内；  $\mathrm{d} = \mathrm{r} \rightarrow$  点在圆上；  $\mathrm{d} > \mathrm{r} \rightarrow$  点在圆外。

2. 直线与圆

- 相切：直线与圆有且只有一个公共点，此时  $d = r$ ；  
• 切线的判定：① 定义法；② 到圆心距离等于半径；③ 经过半径外端且垂直于这条半径的直线是圆的切线。  
- 切线的性质：圆的切线垂直于过切点的半径。

# 圆的计算

1. 弧长公式：  $l = 180\mathrm{n}\pi \mathrm{R}$  （n为圆心角度数，R为圆半径）；

2. 扇形面积公式：扇形；

3. 圆锥侧面积：侧（r为底面半径，l为母线长）；圆锥全面积：全侧底。

2. 相似三角形

• 定义: 对应角相等, 对应边成比例的两个三角形叫做相似三角形, 相似比用 k 表示。

# - 判定定理

1. 平行于三角形一边的直线和其他两边相交，所构成的三角形与原三角形相似（平行线判定法）。  
2. 两角分别相等的两个三角形相似（AA）。  
3. 两边成比例且夹角相等的两个三角形相似（SAS）。  
4. 三边成比例的两个三角形相似（SSS）。

# 性质

1. 对应角相等，对应边成比例；  
2. 对应高、对应中线、对应角平分线的比都等于相似比；  
3. 周长比等于相似比，面积比等于相似比的平方。

- 位似图形：如果两个图形不仅相似，而且对应顶点的连线相交于一点，对应边互相平行，那么这两个图形叫做位似图形，这个点叫做位似中心。位似图形上任意一对对应点到位似中心的距离之比等于位似比。

# 解直角三角形

1. 定义：在直角三角形中，已知除直角外的两个元素（至少一个是边），求其余未知元素的过程。  
2. 依据：① 勾股定理  $a2 + b2 = c2$ ；② 锐角互余  $\angle A + \angle B = 90^\circ$ ；③ 锐角三角函数定义。  
3. 实际应用：测高度、测距离、航海问题等，常结合仰角、俯角、坡度（坡比）等概念。  
4. 投影与视图

# 投影

平行投影: 由平行光线形成的投影 (如太阳光), 同一时刻物高与影长成比例。  
。中心投影：由同一点发出的光线形成的投影（如灯光）。

# - 三视图

。主视图：从正面看得到的图形；  
。左视图：从左面看得到的图形；  
俯视图：从上面看得到的图形；  
。画三视图的原则：长对正、高平齐、宽相等。

# 三、统计与概率模块（中考占比约  $15\%$ ）

1. 统计

- 数据的收集与整理：全面调查（普查）、抽样调查；抽样调查需保证样本的代表性和广泛性。  
数据的代表

1. 平均数：算术平均数  $x = nx1 + x2 + \dots + xn$ ；加权平均数  $x = f1 + f2 + \dots + f kx1$ $f1 + x2f2 + \dots + xkfk$ （ $f$  为权重）。

2. 中位数：将数据从小到大排列后，位于中间位置的数（数据个数为奇数）或中间两个数的平均数（数据个数为偶数）。  
3. 众数：一组数据中出现次数最多的数（可以有多个）。

# 数据的波动

1. 方差：s2=n1[(x1-x)2+(x2-x)2+++(xn-x)2]；  
2. 标准差：方差的算术平方根  $s = s2$  
3. 方差越大，数据的波动越大；方差越小，数据的波动越小。

- 统计图表：条形图、折线图、扇形图、频数分布直方图，需能从图表中提取有效信息。

2. 概率

事件的分类

。必然事件：一定会发生的事件，概率为1；  
。不可能事件：一定不会发生的事件，概率为0；  
随机事件：可能发生也可能不发生的事件，概率  $0 < P < 1$ 。

概率的计算

1. 公式法：对于古典概型，事件包含的等可能结果数所有等可能结果的总数；  
2. 列举法：列表法、树状图法（适用于两步或两步以上的试验）；  
3. 频率估计概率：当试验次数足够大时，频率稳定在某个常数附近，这个常数即为概率。

四、中考常用数学思想方法

1. 数形结合思想：将代数问题与几何图形结合（如二次函数图像与方程的关系）；  
2. 分类讨论思想：当问题存在多种情况时需分类（如等腰三角形的腰和底、圆的位置关系等）；  
3. 转化与化归思想：将复杂问题转化为简单问题（如分式方程转化为整式方程、不规则图形面积转化为规则图形面积）；  
4. 建模思想：将实际问题转化为数学模型（如方程模型、函数模型、几何模型）。
