# 文件内容说明 (File Map)

> 本文档逐目录说明 RAGFlow 0.23.1 的文件功能。当需要快速定位代码时使用。

---

## 根目录

| 路径 | 功能 |
|---|---|
| `pyproject.toml` | Python 项目配置：依赖声明、pytest/ruff/coverage 配置、entry points |
| `CLAUDE.md` | AI 辅助开发指南（供 Claude Code 等工具使用） |
| `README.md` / `README_zh.md` | 中英文项目说明 |
| `LICENSE` | Apache-2.0 协议 |
| `Dockerfile` | 应用 Docker 镜像构建文件 |
| `download_deps.py` | 依赖下载脚本（NLTK 数据、HuggingFace 模型等） |
| `restart_ragflow.sh` | 重启脚本 |
