> **用途**: 供 AI 辅助开发时快速理解项目架构，避免每次重新扫描。
> **最后更新**: 2026-07-09
> **适用版本**: RAGFlow 0.23.1

---

## 一句话概述

RAGFlow 是一款基于深度文档理解的开源 RAG（检索增强生成）引擎，结合 Agent 能力，支持从复杂非结构化数据中构建高保真、可溯源的知识检索系统。

---

## 核心数据流

```
用户操作
    │
    ├─ 上传文档 ──→ deepdoc 解析 ──→ Pipeline 分块 ──→ Embedding 向量化 ──→ ES/Infinity 索引
    │                                              │
    │                                              ├─→ RAPTOR 分层摘要
    │                                              └─→ GraphRAG 知识图谱
    │
    ├─ 创建 Agent ──→ Canvas DSL ──→ Graph 执行 ──→ LLM + 检索 + 工具调用
    │
    └─ 对话问答 ──→ 检索召回 ──→ 重排序 ──→ LLM 生成 ──→ 引用溯源
```

## 四层架构

### 第 1 层：接口层 (`/api/`)

对外暴露的 HTTP API，不包含解析逻辑。

| 组件 | 位置 | 角色 |
|---|---|---|
| Quart App 工厂 | `api/apps/__init__.py` | 创建 Quart 实例，自动注册 Blueprint，配置 Auth/CORS/Swagger |
| 路由模块 | `api/apps/*_app.py` | 各业务领域路由（document, kb, dialog, canvas, chunk 等） |
| SDK API | `api/apps/sdk/` | 对外 SDK REST API（dataset, doc, chat, session, agents, files） |
| 入口 | `api/ragflow_server.py` | 进程启动：DB 初始化 → 服务注册 → HTTP 监听 |

URL 路由规则：
- 管理后台 API：`/<API_VERSION>/<page_name>/<route>`（如 `/v1/document/list`）
- SDK API：`/api/<API_VERSION>/<route>`（如 `/api/v1/datasets`）

### 第 2 层：业务逻辑层 (`/rag/` + `/agent/` + `/graphrag/` + `/deepdoc/`)

所有文档处理和 Agent 逻辑的核心实现。

## 关键中间格式

### Pipeline DSL (JSON)

Pipeline 继承自 Agent Canvas，使用相同的 DSL 格式：

```json
{
  "components": {
    "begin": {
      "obj": { "component_name": "Begin", "params": {} },
      "downstream": ["parser_0"],
      "upstream": []
    },
    "parser_0": {
      "obj": { "component_name": "Parser", "params": { "parser_type": "mineru" } },
      "downstream": ["splitter_0"],
      "upstream": ["begin"]
    }
  }
}
```

### MinerU 解析产物

MinerU 解析输出 `_content_list.json`，经 `_transfer_to_sections` 转换后存入 `MineruSection` 数据库表：

```json
[
  {
    "chunk_id": "唯一ID",
    "type": "text | table | image | equation | list | ...",
    "text": "文本内容",
    "table_body": "<table>HTML</table>",
    "bbox": [x0, y0, x1, y1],
    "page_idx": 0,
    "img_path": "图片路径"
  }
]
```

## 前端架构

```
web/src/
├── pages/         ← 页面组件（按路由组织）
├── components/    ← 通用组件
├── services/      ← API 调用封装
├── hooks/         ← 自定义 Hooks
├── stores/        ← Zustand 状态管理
├── locales/       ← 国际化
├── assets/        ← 静态资源
└── routes.tsx     ← 路由配置
```

- **框架**: React + TypeScript + UmiJS
- **UI 库**: Ant Design + shadcn/ui
- **状态管理**: Zustand
- **样式**: Tailwind CSS + Less

## 技术栈概要

- **Web 框架**: Quart (async Flask 兼容) + uvicorn
- **ORM**: Peewee（支持 MySQL + PostgreSQL）
- **检索引擎**: Elasticsearch / Infinity
- **LLM 调用**: 自研 `LLMBundle` 抽象（支持 OpenAI, Anthropic, Google, Groq, Ollama, 通义千问, 智谱, 火山引擎等 20+ 厂商）
- **PDF 处理**: pypdf, pdfplumber, MinerU API
- **Office 文档**: python-docx, python-pptx, openpyxl, python-calamine
- **OCR**: PaddleOCR, Tesseract
- **异步**: asyncio + httpx
- **对象存储**: MinIO
- **任务队列**: Redis
- **模型源**: HuggingFace Hub
- **前端**: React + TypeScript + UmiJS + Ant Design + Tailwind CSS
