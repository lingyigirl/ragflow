# 配置参数全解 (Configuration Reference)

> 本文档详述 RAGFlow 0.23.1 所有配置项的含义、默认值及影响范围。

---

## 一、配置体系

RAGFlow 的配置分三个层次：

```
docker/.env                    ← 环境变量（Docker 部署时的主要配置入口）
    │
    ▼
docker/service_conf.yaml.template  ← 后端服务配置（MySQL/Redis/ES/MinIO/LLM）
    │
    ▼
API 请求 / 前端操作              ← 运行时配置（解析器参数、对话设置等）
```

---

## 四、运行时配置

### 4.1 Document 解析配置（`parser_config` JSON）

```json
{
  "pages": [[1, 1000000]],
  "table_context_size": 0,
  "image_context_size": 0,
  "chunk_token_num": 1024,
  "delimiter": "\n",
  "layout_recognize": "DeepDOC",
  "mineru_backend": "pipeline",
  "mineru_parse_method": "auto",
  "mineru_lang": "Chinese",
  "mineru_formula_enable": true,
  "mineru_table_enable": true,
  "skip_mineru_section_persist": false,
  "use_submitted_content_list": false
}
```

| 参数 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `pages` | list | `[[1, 1000000]]` | 解析页码范围 |
| `table_context_size` | int | `0` | 表格上下文窗口 |
| `image_context_size` | int | `0` | 图片上下文窗口 |
| `chunk_token_num` | int | `1024` | 分块 Token 数 |
| `delimiter` | str | `\n` | 分隔符 |
| `layout_recognize` | str | `DeepDOC` | 布局识别引擎 |
| `mineru_backend` | str | `pipeline` | MinerU 后端：pipeline / vlm-http-client |
| `mineru_parse_method` | str | `auto` | MinerU 解析方式：auto / txt / ocr |
| `mineru_lang` | str | `Chinese` | MinerU 识别语言 |
| `mineru_formula_enable` | bool | `true` | 公式识别开关 |
| `mineru_table_enable` | bool | `true` | 表格识别开关 |
| `skip_mineru_section_persist` | bool | `false` | 跳过 MinerU Section 持久化 |
| `use_submitted_content_list` | bool | `false` | 使用已提交 content_list |

### 4.2 LLM 设置（`llm_setting` JSON）

```json
{
  "temperature": 0.1,
  "top_p": 0.3,
  "frequency_penalty": 0.7,
  "presence_penalty": 0.4,
  "max_tokens": 512

```
