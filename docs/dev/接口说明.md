# 接口说明 (API)

> 本文档定义 RAGFlow 0.23.1 的 HTTP REST API，涵盖管理后台 API 和对外 SDK API。

---

## 一、认证方式

RAGFlow 使用 Token 认证，两种方式：

### 1.1 Bearer Token（管理后台）

```
Authorization: <access_token>
```

登录后获取的 access_token，通过 `login_required` 装饰器校验。

### 1.2 API Key（SDK API）

```
Authorization: Bearer <api_key>
```

在知识库设置中生成，通过 `api_key_required` 装饰器校验。

#### `mineru_section/doc_chunk_datas` 接口详情

**请求**:
```json
{
  "doc_id": "文档ID（必填）"
}
```

**响应**:
```json
{
  "code": 0,
  "data": {
    "doc_id": "文档ID",
    "count": 100,
    "sections": [
      {
        "chunk_id": "块ID",
        "type": "text | table | image | ...",
        "data": "根据type映射的实际内容",
        "bbox": [x0, y0, x1, y1],
        "page_idx": 0,
        "img_path": "图片路径（可选）",
        "text_level": 0

  }
}
```

## 四、统一响应格式

```json
{
  "code": 0,           // 0=成功, 非0=错误码
  "message": "success",
  "data": {}           // 业务数据
}
```

错误码枚举（`api/constants.py` 和 `common/constants.py`）：
- `RetCode.SUCCESS` = 0
- `RetCode.ARGUMENT_ERROR` = 参数错误
- `RetCode.NOT_FOUND` = 资源不存在
- `RetCode.UNAUTHORIZED` = 未认证

## 五、关键表单/请求体参数

### Document 上传/运行

| 参数 | 类型 | 说明 |
|---|---|---|
| `kb_id` | str | 所属知识库 ID |
| `parser_id` | str | 解析器类型：pdf / docx / excel / ppt / mineru / ... |
| `parser_config` | dict | 解析器配置（chunk 策略、MinerU 参数等） |
| `name` | str | 文件名 |
| `doc_id` | str | 文档 ID |

### MinerU parser_config 常用参数

| 参数 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `mineru_backend` | str | `pipeline` | MinerU 后端：pipeline / vlm-http-client |
| `mineru_parse_method` | str | `auto` | 解析方式：auto / txt / ocr |
| `mineru_lang` | str | `Chinese` | 识别语言 |
| `mineru_formula_enable` | bool | true | 公式识别 |
| `mineru_table_enable` | bool | true | 表格识别 |
| `skip_mineru_section_persist` | bool | false | 跳过 MinerU Section 持久化 |
| `use_submitted_content_list` | bool | false | 使用已提交的 content_list |
| `chunk_token_num` | int | 1024 | 分块 Token 数 |
| `delimiter` | str | `\n` | 分隔符 |
| `layout_recognize` | str | `DeepDOC` | 布局识别引擎 |

## 六、环境变量（服务端）

| 变量 | 默认值 | 说明 |
|---|---|---|
| `MINERU_APISERVER` | `http://host.docker.internal:9987` | MinerU API 服务地址 |
| `QUART_RESPONSE_TIMEOUT` | 600 | Quart 响应超时（秒） |
| `QUART_BODY_TIMEOUT` | 600 | Quart 请求体超时（秒） |
| `MAX_CONTENT_LENGTH` | 1073741824 | 最大请求体（字节，默认 1GB） |
| `DATABASE_TYPE` | mysql | 数据库类型：mysql / postgres |
| `DOC_ENGINE` | elasticsearch | 检索引擎：elasticsearch / infinity |
| `WS` | 2 | Task Executor Worker 数量 |
| `HF_ENDPOINT` | (空) | HuggingFace 镜像站 |
| `RAGFLOW_DEBUGPY_LISTEN` | 0 | Debugpy 调试端口（0=禁用） |
