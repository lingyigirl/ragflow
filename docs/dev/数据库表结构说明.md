# 数据库表结构说明 (Database Schema)

> 本文档描述 RAGFlow 0.23.1 的数据库表结构（Peewee ORM，支持 MySQL 和 PostgreSQL）。

---

## 一、基础模型

所有表继承自 `DataBaseModel` → `BaseModel`，自动包含以下字段：

| 字段 | 类型 | 说明 |
|---|---|---|
| `create_time` | BigIntegerField | 创建时间戳 |
| `create_date` | DateTimeField | 创建日期 |
| `update_time` | BigIntegerField | 更新时间戳 |
| `update_date` | DateTimeField | 更新日期 |

主键通常为 32 位 UUID 字符串 (`CharField(max_length=32, primary_key=True)`)。

## 四、自定义字段类型

`api/db/db_models.py` 定义了专用字段类型：

| 类型 | 基类 | 说明 |
|---|---|---|
| `JSONField` | LongTextField | 自动序列化/反序列化 JSON |
| `ListField` | JSONField | 列表类型（JSON 存储） |
| `SerializedField` | LongTextField | Pickle 序列化 |
| `LongTextField` | TextField | 适配 MySQL(LONGTEXT) vs PostgreSQL(TEXT) |
