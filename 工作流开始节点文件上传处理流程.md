# 工作流开始节点（Begin Node）源码与运行流程

## 1. 概述

工作流开始节点（Begin Node）是 RAGFlow 工作流系统的入口节点，负责接收用户输入、处理参数，并将数据传递给下游节点。本文档详细说明了开始节点的源码结构、运行流程和相关逻辑。

## 3. 后端实现

### 3.1 Begin 组件定义

**文件位置**: `agent/component/begin.py`

**父类**: `UserFillUp` (定义在 `agent/component/fillup.py`)

开始节点在后端继承自 `UserFillUp` 组件：

```python
class BeginParam(UserFillUpParam):
    """
    定义 Begin 组件的参数类
    """
    def __init__(self):
        super().__init__()
        self.mode = "conversational"  # 默认模式为对话模式
        self.prologue = "Hi! I'm your smart assistant. What can I do for you?"  # 默认开场白

    def check(self):
        # 验证模式值是否有效
        self.check_valid_value(
            self.mode, 
            "The 'mode' should be either `conversational` or `task`", 
            ["conversational", "task", "Webhook"]
        )

    def get_input_form(self) -> dict[str, dict]:
        # 返回输入表单配置
        return getattr(self, "inputs")


class Begin(UserFillUp):
    component_name = "Begin"  # 组件名称

    def _invoke(self, **kwargs):
        """
        执行开始节点的核心逻辑
        处理用户输入的参数，并将其设置为输出
        """
        # 检查任务是否被取消
        if self.check_if_canceled("Begin processing"):
            return

        # 遍历所有输入参数
        for k, v in kwargs.get("inputs", {}).items():
            # 再次检查任务是否被取消
            if self.check_if_canceled("Begin processing"):
                return

            # 处理文件类型参数
            if isinstance(v, dict) and v.get("type", "").lower().find("file") >= 0:
                # 如果是可选参数且值为空，设置为 None
                if v.get("optional") and v.get("value", None) is None:
                    v = None
                else:
                    # 通过 FileService 获取文件内容
                    v = FileService.get_files([v["value"]])
            else:
                # 非文件类型参数，直接获取值
                v = v.get("value")
            
            # 设置输出和输入值
            self.set_output(k, v)
            self.set_input_value(k, v)

    def thoughts(self) -> str:
        """返回组件的思考过程（开始节点为空）"""
        return ""
```

**关键逻辑**:
- 继承自 `UserFillUp`，具备用户输入填充功能
- 处理多种类型的输入参数，特别是文件类型
- 将处理后的参数设置为输出，供下游节点使用

**相关函数**:
- `check_if_canceled()`: 检查任务是否被取消（定义在 `agent/component/base.py`）
- `set_output()`: 设置组件输出（定义在 `agent/component/base.py`）
- `set_input_value()`: 设置输入值（定义在 `agent/component/base.py`）
- `FileService.get_files()`: 获取文件内容（定义在 `api/db/services/file_service.py`）

### 3.2 工作流执行流程

**文件位置**: `agent/canvas.py`

**类**: `Canvas` (继承自 `Graph`)

工作流的执行入口在 `Canvas.run()` 方法中：

```python
async def run(self, **kwargs):
    """
    工作流执行主方法
    """
    st = time.perf_counter()  # 记录开始时间
    self._loop = asyncio.get_running_loop()
    self.message_id = get_uuid()  # 生成消息 ID
    created_at = int(time.time())
    
    # 添加用户输入到历史记录
    self.add_user_input(kwargs.get("query"))
    
    # 重置所有组件状态
    for k, cpn in self.components.items():
        self.components[k]["obj"].reset(True)

    # 处理 Webhook 模式的 payload
    if kwargs.get("webhook_payload"):
        for k, cpn in self.components.items():
            if (self.components[k]["obj"].component_name.lower() == "begin" and 
                self.components[k]["obj"]._param.mode == "Webhook"):
                payload = kwargs.get("webhook_payload", {})
                if "input" in payload:
                    self.components[k]["obj"].set_input_value("request", payload["input"])
                for kk, vv in payload.items():
                    if kk == "input":
                        continue
                    self.components[k]["obj"].set_output(kk, vv)

    # 设置全局变量
    for k in kwargs.keys():
        if k in ["query", "user_id", "files"] and kwargs[k]:
            if k == "files":
                self.globals[f"sys.{k}"] = await self.get_files_async(kwargs[k])
            else:
                self.globals[f"sys.{k}"] = kwargs[k]
    
    # 增加对话轮次
    if not self.globals["sys.conversation_turns"]:
        self.globals["sys.conversation_turns"] = 0
    self.globals["sys.conversation_turns"] += 1

    # 事件装饰器函数
    def decorate(event, dt):
        return {
            "event": event,
            "message_id": self.message_id,
            "created_at": created_at,
            "task_id": self.task_id,
            "data": dt
        }

    # 如果路径为空或最后一个不是 UserFillUp，添加 begin 节点
    if not self.path or self.path[-1].lower().find("userfillup") < 0:
        self.path.append("begin")
        self.retrieval.append({"chunks": [], "doc_aggs": []})

    # 检查任务是否被取消
    if self.is_canceled():
        msg = f"Task {self.task_id} has been canceled before starting."
        logging.info(msg)
        raise TaskCanceledException(msg)

    # 发送工作流开始事件
    yield decorate("workflow_started", {"inputs": kwargs.get("inputs")})
    self.retrieval.append({"chunks": {}, "doc_aggs": {}})

    # 批量执行节点的异步函数
    async def _run_batch(f, t):
        """批量执行路径中的节点"""
        if self.is_canceled():
            msg = f"Task {self.task_id} has been canceled during batch execution."
            logging.info(msg)
            raise TaskCanceledException(msg)

        loop = asyncio.get_running_loop()
        tasks = []

        def _run_async_in_thread(coro_func, **call_kwargs):
            return asyncio.run(coro_func(**call_kwargs))

        i = f
        while i < t:
            cpn = self.get_component_obj(self.path[i])
            task_fn = None
            call_kwargs = None

            # 处理 Begin 和 UserFillUp 节点
            if cpn.component_name.lower() in ["begin", "userfillup"]:
                call_kwargs = {"inputs": kwargs.get("inputs", {})}
                task_fn = cpn.invoke
                i += 1
            else:
                # 其他节点需要检查输入依赖
                for _, ele in cpn.get_input_elements().items():
                    if (isinstance(ele, dict) and ele.get("_cpn_id") and 
                        ele.get("_cpn_id") not in self.path[:i] and 
                        self.path[0].lower().find("userfillup") < 0):
                        self.path.pop(i)
                        t -= 1
                        break
                else:
                    call_kwargs = cpn.get_input()
                    task_fn = cpn.invoke
                    i += 1

            if task_fn is None:
                continue

            # 执行节点任务
            invoke_async = getattr(cpn, "invoke_async", None)
            if invoke_async and asyncio.iscoroutinefunction(invoke_async):
                tasks.append(loop.run_in_executor(
                    self._thread_pool, 
                    partial(_run_async_in_thread, invoke_async, **(call_kwargs or {}))
                ))
            else:
                tasks.append(loop.run_in_executor(
                    self._thread_pool, 
                    partial(task_fn, **(call_kwargs or {}))
                ))

        if tasks:
            await asyncio.gather(*tasks)

    # 主执行循环
    self.error = ""
    idx = len(self.path) - 1
    partials = []
    tts_mdl = None
    
    while idx < len(self.path):
        to = len(self.path)
        
        # 发送节点开始事件
        for i in range(idx, to):
            yield decorate("node_started", {
                "inputs": None, 
                "created_at": int(time.time()),
                "component_id": self.path[i],
                "component_name": self.get_component_name(self.path[i]),
                "component_type": self.get_component_type(self.path[i]),
                "thoughts": self.get_component_thoughts(self.path[i])
            })
        
        # 批量执行节点
        await _run_batch(idx, to)
        to = len(self.path)
        
        # 后处理：处理节点执行结果
        for i in range(idx, to):
            cpn = self.get_component(self.path[i])
            cpn_obj = self.get_component_obj(self.path[i])
            
            # 处理 Message 组件的流式输出
            if cpn_obj.component_name.lower() == "message":
                # ... 处理消息流式输出逻辑
            
            # 处理错误和异常分支
            if cpn_obj.error():
                ex = cpn_obj.exception_handler()
                if ex and ex["goto"]:
                    self.path.extend(ex["goto"])
                    other_branch = True
                elif ex and ex["default_value"]:
                    yield decorate("message", {"content": ex["default_value"]})
                    yield decorate("message_end", {})
                else:
                    self.error = cpn_obj.error()
            
            # 发送节点完成事件
            if cpn_obj.component_name.lower() not in ("iteration", "loop"):
                if isinstance(cpn_obj.output("content"), partial):
                    if self.error:
                        cpn_obj.set_output("content", None)
                        yield _node_finished(cpn_obj)
                    else:
                        partials.append(self.path[i])
                else:
                    yield _node_finished(cpn_obj)
            
            # 扩展执行路径（根据节点类型决定下一步）
            if cpn_obj.component_name.lower() in ("iterationitem", "loopitem") and cpn_obj.end():
                iter = cpn_obj.get_parent()
                yield _node_finished(iter)
                _extend_path(self.get_component(cpn["parent_id"])["downstream"])
            elif cpn_obj.component_name.lower() in ["categorize", "switch"]:
                _extend_path(cpn_obj.output("_next"))
            elif cpn_obj.component_name.lower() in ("iteration", "loop"):
                _append_path(cpn_obj.get_start())
            elif cpn_obj.component_name.lower() == "exitloop" and cpn_obj.get_parent().component_name.lower() == "loop":
                _extend_path(self.get_component(cpn["parent_id"])["downstream"])
            elif not cpn["downstream"] and cpn_obj.get_parent():
                _append_path(cpn_obj.get_parent().get_start())
            else:
                _extend_path(cpn["downstream"])

        if self.error:
            logging.error(f"Runtime Error: {self.error}")
            break
        idx = to

        # 检查是否有 UserFillUp 节点需要用户输入
        if any([self.get_component_obj(c).component_name.lower() == "userfillup" for c in self.path[idx:]]):
            path = [c for c in self.path[idx:] if self.get_component(c)["obj"].component_name.lower() == "userfillup"]
            path.extend([c for c in self.path[idx:] if self.get_component(c)["obj"].component_name.lower() != "userfillup"])
            another_inputs = {}
            tips = ""
            for c in path:
                o = self.get_component_obj(c)
                if o.component_name.lower() == "userfillup":
                    o.invoke()
                    another_inputs.update(o.get_input_elements())
                    if o.get_param("enable_tips"):
                        tips = o.output("tips")
            self.path = path
            yield decorate("user_inputs", {"inputs": another_inputs, "tips": tips})
            return
    
    # 发送工作流完成事件
    self.path = self.path[:idx]
    if not self.error:
        yield decorate("workflow_finished", {
            "inputs": kwargs.get("inputs"),
            "outputs": self.get_component_obj(self.path[-1]).output(),
            "elapsed_time": time.perf_counter() - st,
            "created_at": st,
        })
        self.history.append(("assistant", self.get_component_obj(self.path[-1]).output()))
    elif "Task has been canceled" in self.error:
        yield decorate("workflow_finished", {
            "inputs": kwargs.get("inputs"),
            "outputs": "Task has been canceled",
            "elapsed_time": time.perf_counter() - st,
            "created_at": st,
        })
```

**关键执行步骤**:
1. 初始化工作流执行环境（生成 message_id、创建时间戳等）
2. 重置所有组件状态（`reset(True)`）
3. 处理 Webhook payload（如果适用）
4. 设置全局变量（`sys.query`、`sys.user_id`、`sys.files` 等）
5. 增加对话轮次（`sys.conversation_turns`）
6. 将 "begin" 节点添加到执行路径（`self.path.append("begin")`）
7. 发送 `workflow_started` 事件
8. 批量执行路径中的节点（`_run_batch()`，Begin 节点接收 inputs 参数）
9. 处理节点执行结果和错误
10. 根据节点类型扩展执行路径（`_extend_path()`、`_append_path()`）
11. 发送 `workflow_finished` 事件

**相关函数**:
- `add_user_input()`: 添加用户输入到历史记录（第 716 行）
- `get_files_async()`: 异步处理文件列表（第 737 行）
- `get_component_obj()`: 获取组件对象（定义在 `agent/canvas.py` 的 `Graph` 类）
- `get_component_name()`: 获取组件名称（定义在 `agent/canvas.py` 的 `Graph` 类）
- `get_component_type()`: 获取组件类型（定义在 `agent/canvas.py` 的 `Graph` 类）
- `get_component_thoughts()`: 获取组件思考过程（第 812 行）
- `is_canceled()`: 检查任务是否被取消（定义在 `agent/canvas.py` 的 `Graph` 类）

async def completion(tenant_id, agent_id, session_id=None, **kwargs):
    """
    工作流执行接口
    """
    query = kwargs.get("query", "") or kwargs.get("question", "")  # 获取用户问题
    files = kwargs.get("files", [])  # 获取上传的文件
    inputs = kwargs.get("inputs", {})  # 获取开始节点的输入参数
    user_id = kwargs.get("user_id", "")  # 获取用户 ID

    # 如果提供了 session_id，从会话中恢复工作流状态
    if session_id:
        e, conv = API4ConversationService.get_by_id(session_id)
        assert e, "Session not found!"
        if not conv.message:
            conv.message = []
        if not isinstance(conv.dsl, str):
            conv.dsl = json.dumps(conv.dsl, ensure_ascii=False)
        canvas = Canvas(conv.dsl, tenant_id, agent_id)
    else:
        # 创建新的工作流实例
        e, cvs = UserCanvasService.get_by_id(agent_id)
        assert e, "Agent not found."
        assert cvs.user_id == tenant_id, "You do not own the agent."
        if not isinstance(cvs.dsl, str):
            cvs.dsl = json.dumps(cvs.dsl, ensure_ascii=False)
        session_id = get_uuid()
        canvas = Canvas(cvs.dsl, tenant_id, agent_id, canvas_id=cvs.id)
        canvas.reset()
        conv = {
            "id": session_id,
            "dialog_id": cvs.id,
            "user_id": user_id,
            "message": [],
            "source": "agent",
            "dsl": cvs.dsl,
            "reference": []
        }
        API4ConversationService.save(**conv)
        conv = API4Conversation(**conv)

    message_id = str(uuid4())
    conv.message.append({
        "role": "user",
        "content": query,
        "id": message_id
    })
    
    txt = ""
    # 执行工作流，inputs 参数会传递给 Begin 节点
    async for ans in canvas.run(query=query, files=files, user_id=user_id, inputs=inputs):
        ans["session_id"] = session_id
        if ans["event"] == "message":
            txt += ans["data"]["content"]
            if ans["data"].get("start_to_think", False):
                txt += "<think>"
            elif ans["data"].get("end_to_think", False):
                txt += "</think>"
        yield "data:" + json.dumps(ans, ensure_ascii=False) + "\n\n"

    conv.message.append({"role": "assistant", "content": txt, ...})
    # ... 保存会话

**请求参数**:

### 5.2 输入参数转换函数

**函数**: `transferInputsArrayToObject()`

**功能**: 将开始节点的输入参数数组转换为对象格式，用于 API 请求

```tsx
export function transferInputsArrayToObject(inputs: BeginQuery[] = []) {
  /**
   * 将输入参数数组转换为对象格式
   * 
   * @param inputs - 输入参数数组，每个元素包含 key, type, value, optional, name 等字段
   * @returns 对象格式的输入参数，key 为参数键，value 为参数配置（不包含 key 字段）
   * 
   * 示例:
   * 输入: [{ key: "name", type: "line", value: "test", optional: false, name: "Name" }]
   * 输出: { name: { type: "line", value: "test", optional: false, name: "Name" } }
   */
  return inputs.reduce<Record<string, Omit<BeginQuery, 'key'>>>((pre, cur) => {
    pre[cur.key] = omit(cur, 'key');
    return pre;
  }, {});
}
```

### 5.3 输入参数构建函数

**文件位置**: `web/src/pages/agent/form/begin-form/utils.ts`

**函数**: `buildBeginInputListFromObject()`

**功能**: 将对象格式的输入参数转换为数组格式，用于表单显示

```tsx
export function buildBeginInputListFromObject(
  inputs: Record<string, Omit<BeginQuery, 'key'>>,
) {
  /**
   * 将对象格式的输入参数转换为数组格式
   * 
   * @param inputs - 对象格式的输入参数，key 为参数键，value 为参数配置
   * @returns 输入参数数组，每个元素包含完整的参数信息（包括 key）
   * 
   * 示例:
   * 输入: { name: { type: "line", value: "test", optional: false, name: "Name" } }
   * 输出: [{ key: "name", type: "line", value: "test", optional: false, name: "Name" }]
   */
  return Object.entries(inputs || {}).reduce<BeginQuery[]>(
    (pre, [key, value]) => {
      pre.push({ ...(value || {}), key });
      return pre;
    },
    [],
  );
}
```

### 5.4 表单值处理 Hook

**文件位置**: `web/src/pages/agent/form/begin-form/use-values.ts`

**功能**: 获取并处理开始节点表单的默认值和当前值

```tsx
export function useValues(node?: RAGFlowNodeType) {
  /**
   * 获取开始节点表单的值
   * - 如果节点没有表单数据，返回默认值
   * - 如果节点有表单数据，将对象格式的 inputs 转换为数组格式
   */
  const defaultValues = useMemo(
    () => ({
      enablePrologue: true,
      prologue: t('chat.setAnOpenerInitial'),
      mode: AgentDialogueMode.Conversational,
      inputs: [],
    }),
    [t],
  );

  const values = useMemo(() => {
    const formData = node?.data?.form;
    if (isEmpty(formData)) {
      return defaultValues;
    }
    // 将对象格式的 inputs 转换为数组格式
    const inputs = buildBeginInputListFromObject(formData?.inputs);
    return { ...(formData || {}), inputs };
  }, [defaultValues, node?.data?.form]);

  return values;
}
```

### 5.5 表单变化监听 Hook

**文件位置**: `web/src/pages/agent/form/begin-form/use-watch-change.ts`

**函数**: `useWatchFormChange()`

**功能**: 监听表单变化，自动更新节点数据，处理 Webhook 模式的输出配置

```tsx
export function useWatchFormChange(id?: string, form?: UseFormReturn) {
  /**
   * 监听表单变化并更新节点数据
   * - 监听表单的 isDirty 状态
   * - 将数组格式的 inputs 转换为对象格式
   * - 如果是 Webhook 模式，根据 schema 生成 outputs
   */
  let values = useWatch({ control: form?.control });
  const updateNodeForm = useGraphStore((state) => state.updateNodeForm);

  useEffect(() => {
    if (id) {
      values = form?.getValues() || {};
      let outputs: Record<string, any> = {};

      // Webhook 模式下，根据 schema 生成 outputs
      if (
        values.mode === AgentDialogueMode.Webhook &&
        !isEmpty(values.schema)
      ) {
        outputs = transformRequestSchemaToOutput(values.schema);
      }

      const nextValues = {
        ...values,
        inputs: transferInputsArrayToObject(values.inputs),  // 转换为对象格式
        outputs,
      };

      updateNodeForm(id, nextValues);  // 更新节点数据
    }
  }, [form?.formState.isDirty, id, updateNodeForm, values]);
}
```

## 9. 文件上传处理

开始节点支持文件类型参数，处理流程如下：

1. **前端上传文件**:
   - 用户在前端选择文件
   - 文件上传到服务器，获得文件 ID

2. **传递文件参数**:
   ```typescript
   inputs: {
     "file_var": {
       "type": "file",
       "value": "file_id_123",  // 文件 ID
       "optional": false
     }
   }
   ```

3. **后端处理**:
   ```python
   # 在 Begin._invoke() 中
   if isinstance(v, dict) and v.get("type", "").lower().find("file") >= 0:
       if v.get("optional") and v.get("value", None) is None:
           v = None
       else:
           # 通过 FileService 获取文件内容
           v = FileService.get_files([v["value"]])
   ```

4. **文件服务**:
   - `FileService.get_files()` 根据文件 ID 列表获取文件内容
   - 返回文件数据供下游节点使用

## 10. Webhook 模式

当开始节点配置为 Webhook 模式时：

1. **前端显示 Webhook URL**
2. **接收外部 HTTP 请求**:
   ```python
   if kwargs.get("webhook_payload"):
       for k, cpn in self.components.items():
           if (self.components[k]["obj"].component_name.lower() == "begin" and 
               self.components[k]["obj"]._param.mode == "Webhook"):
               payload = kwargs.get("webhook_payload", {})
               if "input" in payload:
                   self.components[k]["obj"].set_input_value("request", payload["input"])
               for kk, vv in payload.items():
                   if kk == "input":
                       continue
                   self.components[k]["obj"].set_output(kk, vv)
   ```

3. **处理 Webhook payload**:
   - 将 payload 中的 "input" 字段设置为输入值
   - 其他字段直接设置为输出

## 11. 总结

工作流开始节点（Begin Node）是 RAGFlow 工作流系统的核心入口，主要功能包括：

1. **参数接收**: 接收用户输入的各种类型参数（文本、数字、布尔值、选项、文件等）
2. **模式支持**: 支持对话模式、任务模式和 Webhook 模式
3. **数据传递**: 将处理后的参数传递给下游节点
4. **事件通知**: 发送工作流开始事件，通知前端工作流已启动
5. **文件处理**: 支持文件类型参数的上传和处理
6. **Webhook 集成**: 支持通过 Webhook 接收外部请求

开始节点的设计遵循了组件化、可扩展的原则，为整个工作流系统提供了稳定可靠的入口。
